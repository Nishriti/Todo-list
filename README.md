# Task Management App

A responsive To-Do List application built with React.js for managing daily tasks.

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Dynamic task updates
- Clean and responsive user interface

## Technologies Used

- React.js
- JavaScript
- HTML
- CSS

## Getting Started

### Install dependencies

npm install

### Run the application

npm start

The application will run at:

http://localhost:3000
